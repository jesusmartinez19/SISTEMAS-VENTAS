Proyecto: Sistema de Compras y Ventas
Concepto: Aplicacion web desarrollada en PHP7 y MYSQL para la gestion de compras y ventas.Utiliso una arquitectura MODELO-VISTA-CONTROLADOR (MVC) y tiene una interfaz de usuario amigable echo en Boostrap
 
1.Descripcion: EL sistema permite gestionar el ciclo completo de ventas y compras incluyendo la administraciond de productos, cliente, proveedores y reportes de ventas.
2.Caracteristicas:
Gestion de productos: tiene el mantenimiento completo(CRUD) , Agregar,editar,eliminar y listar productos
3.Ventas: Registro de ventas con generacion de tickets
4.Gestion de clientes y proveedores: Registro y actualizacion de datos.
5.Compras:Registro de compras y actualizacion de inventario.
6.Reportes: Visualizacion de ventas  por fecha y productos vendidos
7.Interfaz amigable: Diseño responsive con Bootstrap

Herramientas:
Backend:php7 con programacion orientado a objetos
Front-end: HMTL5,CSS,Bootstrap,Jquery
Base de datos: MYSQL(MARIADB)
Arquitectura: Modelo-Vista-Controlador(MVC)
